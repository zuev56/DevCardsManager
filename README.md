## ПО для работы с образами карт Mifare (Windows/Linux).

[**Скачать**](https://github.com/zuev56/DevCardsManager/releases)

- Имитирует прикладывание карты (перемещение файла с образом карты (*.bin) в заданный каталог из каталога со всеми образами)
  - Копирование в буфер обмена имени карты при прикладывании (удобно, когда имя карты является её паролем)
  - Сохранение или сброс внесённых изменений при убирании карты в зависимости от заданых настроек
  - Временное прикладывание (через заданный интервал карта будет автоматически убрана)
- Закрепление часто используемых карт в начале списка
- Фильтрация по имени, UID и CSN
- Просмотр базовой информацию о карте (модель карты, UID, CSN (Chip Serial Number))
- Настройка вывода необходимых контролов на карту
